### 实验拓扑
![598](images/Pasted%20image%2020260825162000.png)
### 实验需求
- 按照图示配置 PC3 和 PC4 的 IP 地址
- 在 SW1 和 SW2 的两条直连链路上配置链路聚合，实现链路冗余，并可以增加传输带宽
- SW1 和 SW2 之间的直连链路要配置为 Trunk 类型，允许所有 VLAN 通过
- 中断 SW1 和 SW2 之间的一条直连链路，测试 PC3 和 PC4 是否仍然能够继续访问
### 配置步骤

#### 1. PC 配置 IP 地址（略）

#### 2. 在 SW1 和 SW2 的直连链路上配置链路聚合
**分析**：SW1 和 SW2 之间通过 `g1/0/1` 和 `g1/0/2` 接口直连，需要在两台交换机上分别创建聚合接口，并把 `g1/0/1` 和 `g1/0/2` 接口加入到聚合接口，形成链路聚合。被聚合的物理接口的 VLAN 配置和接口类型要保持一致，所以在配置链路聚合前，物理端口不要做任何其他配置，保持默认状态即可。
```
交换机1的配置：
interface Bridge-Aggregation 1
interface g1/0/1
port link-aggregation group 1
interface g1/0/2
port link-aggregation group 1

交换机2的配置：
interface Bridge-Aggregation 1
interface g1/0/1
port link-aggregation group 1
interface g1/0/2
port link-aggregation group 1
```

查看链路聚合状态，确认已成功运行（下面以交换机1为例）：

```

Port: A -- Auto

  GE1/0/1          S       32768    1
  GE1/0/2          S       32768    1
```
#### 3. SW1 和 SW2 之间的直连链路配置为 Trunk，允许所有 VLAN 通过

**分析**：物理接口加入到聚合接口后，会自动继承聚合接口的 VLAN 相关配置，所以不需要在物理接口上分别配置 Trunk，只需要在聚合接口下配置 Trunk 即可。
```
交换机1的配置：
interface Bridge-Aggregation 1
port link-type trunk
port trunk permit vlan all

交换机2的配置：
interface Bridge-Aggregation 1
port link-type trunk
port trunk permit vlan all
```
#### 4. 中断一条直连链路，测试连通性

**分析**：链路聚合会自动把 SW1 和 SW2 之间的流量进行负载均衡，某一条链路中断连接后，仍然还有另外一条链路可以继续通讯，所以 PC3 和 PC4 可以继续访问。

**步骤1**：进入 SW1 的 `g1/0/1` 接口视图，使用 `shutdown` 命令关闭接口。

```
interface g1/0/1
shutdown
```
