### 实验拓扑
![](images/Pasted%20image%2020260902215547.png)
## 实验需求
1. 按照图示配置 IP 地址
2. 私网 A 通过 R1 接入到互联网，私网 B 通过 R3 接入到互联网
3. 私网 A 内部存在 Vlan10 和 Vlan20，通过 R1 上单臂路由访问外部网络
4. 私网 A 通过 NAPT 使 Vlan10 和 Vlan20 都能够使用 R1 的公网地址访问互联网
5. 私网 B 通过在 R3 上配置 EASY IP 访问互联网
6. 私网 A 配置 NAT SERVER 把 FTPA 的 FTP 服务发布到公网，使 PCB 可以访问
### 实验解法
#### 1.配置 IP 地址
```
# FTP-A的配置如下：
int g0/0
ip add 192.168.1.1 24

# PCA的配置如下：
int g0/0
ip add 192.168.2.1 24

# R1的配置如下：
int g0/1
ip add 100.1.1.1 24

# R2的配置如下：
int g0/0
ip add 100.1.1.2 24
int g0/1
ip add 100.2.2.2 24

# R3的配置如下：
int g0/0
ip add 100.2.2.3 24
int g0/1
ip add 192.168.1.3 24

# PCB的配置如下：
int g0/0
ip add 192.168.1.1 24
```
#### 2.R1 和 R3 上配置默认路由指向公网
```
# R1的配置如下：
ip route-static 0.0.0.0 0 100.1.1.2

# R3的配置如下：
ip route-static 0.0.0.0 0 100.2.2.2
```
#### 3.私网 A 内部单臂路由配置
```
# FTP-A的配置如下：
ip route-static 0.0.0.0 0 192.168.1.254

# PCA的配置如下：
ip route-static 0.0.0.0 0 192.168.2.254

# SWA的配置如下：
vlan 10
port g1/0/1
vlan 20
port g1/0/2
int g1/0/3
port link-type trunk
port trunk permit vlan 10 20

# R1的配置如下：
interface g0/0.1
vlan-type dot1q vid 10
ip address 192.168.1.254 24
interface g0/0.2
vlan-type dot1q vid 20
ip address 192.168.2.254 24
```
#### 4.私网 A 通过 NAPT 使 Vlan10 和 Vlan20 都能够使用 R1 的公网地址访问互联网

分析：根据需求得知，ACL 需要配置允许 192.168.1.0/24 和 192.168.2.0/24 网段；私网 A 只有 1 个公网地址可用，意味着创建的 NAT 地址池起始和结束地址就都是 100.1.1.1
##### 步骤 1：R1 上创建基本 ACL，允许 192.168.1.0/24 和 192.168.2.0/24 网段
```
acl basic 2000
rule permit source 192.168.1.0 0.0.0.255
rule permit source 192.168.2.0 0.0.0.255
```
##### 步骤 2：R1 上创建 NAT 地址池，设置公网地址
```
nat address-group 1
address 100.1.1.1 100.1.1.1
```

##### 步骤 3：在 R1 的公网接口上配置 NAPT
```
interface g0/1
nat outbound 2000 address-group 1 
```

#### 5.私网 B 通过在 R3 上配置 EASY IP 访问互联网

分析：根据需求得知，ACL 需要配置允许 192.168.1.0/24 网段；使用 EASY IP，就无需配置 NAT 地址池，直接在公网接口上配置即可，EASY IP 会自动识别公网接口的 IP 地址。
##### 步骤 1：R3 上创建基本 ACL，允许 192.168.1.0/24 网段
```
acl basic 2000
rule permit source 192.168.1.0 0.0.0.255
```
##### 步骤 2：在 R3 的公网接口上配置 EASY IP
```
interface g0/0
nat outbound 2000
```

#### 6.私网 A 配置 NAT SERVER 把 FTPA 的 FTP 服务发布到公网，使 PCB 可以访问

分析：根据需求得知，需要发布 FTPA 的 FTP 服务，也就是把 R1 的公网地址的 20 和 21 端口映射到 FTPA 的私网地址
##### 步骤 1：配置 FTP 服务
```
ftp server enable
```
##### 步骤 2：在 R1 的公网接口上配置 NAT SERVER，映射端口 20 和 21
```
int g0/1
nat server protocol tcp global 100.1.1.1 20 21 inside 192.168.1.10 20 21
```
##### 步骤 3：在 PCB 上测试是否能够通过 R1 的公网地址访问 FTPA 的 FTP 服务
```
<PCB>ftp 100.1.1.1
Press CTRL+C to abort.
ftp: connect: Connection refused
ftp>
ftp> quit
<PCB>
```
