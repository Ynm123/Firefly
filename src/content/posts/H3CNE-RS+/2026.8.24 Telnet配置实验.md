### 实验拓扑
![](images/Pasted%20image%2020260824170308.png)
> 实验前需要先配置路由器的G0/0接口的IP地址，请确保真实PC与路由器网络互通（可通过ping测试）。

### 实验需求
1. 按照图示连接到真机，并配置IP地址（真机IP地址配置到VirtualBox Host-Only Ethernet Adapter网卡）
2. 在R1上开启Telnet服务，创建用户`wangdaye`，密码`123456`用于身份验证
3. 在真机上使用S-CRT通过Telnet登录R1
### 配置步骤

#### 步骤1：开启Telnet服务并创建用户
```text
# 开启Telnet服务
telnet server enable

# 创建管理用户wangdaye，密码ynm@123456，允许Telnet登录，赋予最高权限15
local-user wangdaye class manage
password simple ynm@123456
service-type telnet
authorization-attribute user-role level-15
```
> ⚠️ 注意：`password simple` 会以明文存储密码，实际生产环境建议使用 `password hash` 增强安全性。
#### 步骤2：配置VTY线路认证模式
```
# 进入VTY 0~4线路，设置认证模式为scheme（本地AAA），并指定默认权限级别
user-interface vty 0 4
authentication-mode scheme
user-role level-15
```
### 验证测试
打开 Xshell，点击“新建”会话。协议选择 TELNET，主机填写路由器接口 IP（192.168.56.2），端口号保持默认 23。 点击“连接”，Xshell 会提示输入用户名，输入 wangdaye，然后输入密码 ynm@123456（注意密码输入时不显示字符）。登录成功后，将看到路由器命令行提示符（如 \<H3C\>）。
