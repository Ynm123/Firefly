### 实验拓扑

### 实验需求

1. 按照图示为R1配置IP地址
2. 配置R1为DHCP服务器，提供服务的地址池为`192.168.1.0/24`网段，网关为`192.168.1.254`，DNS服务器地址为`202.103.24.68`，`202.103.0.117`
3. `192.168.1.10-192.168.1.20`为专用地址段，要求不能用于自动分配
4. PC1和PC2都能获取到`192.168.1.0/24`网段的IP地址
### 配置

#### 1. 开启 DHCP 服务

在系统视图下开启 DHCP 功能：

```
interface GigabitEthernet0/0
ip address 192.168.1.254 255.255.255.0
quit

#排除特定地址:为了防止某些 IP 被动态分配给普通客户端（比如保留给服务器），需要排除一段地址
dhcp server forbidden-ip 192.168.1.10 192.168.1.20
```

#### 2. 创建 DHCP 地址池

创建名为 `1` 的地址池，并配置分配参数：

```
dhcp enable
dhcp server ip-pool 1
network 192.168.1.0 mask 255.255.255.0
gateway-list 192.168.1.254
dns-list 202.103.24.68 202.103.0.117
quit
```
### 验证与测试

配置完成后，将 PC1 和 PC2 的网络设置为“自动获取 IP 地址”（DHCP 方式）。
