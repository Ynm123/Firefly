为你整理了一份面试常考的漏洞清单，主要基于Vulhub靶场。下面这份表格涵盖了目前业界最常见、面试最常问的漏洞，可以优先练习。

### 🎯 面试必练漏洞清单

| 漏洞名称               | CVE 编号                          | 漏洞类型             | 简要说明与面试要点                                                    |
| :----------------- | :------------------------------ | :--------------- | :----------------------------------------------------------- |
| **Apache Log4j2**  | **CVE-2021-44228**              | **远程代码执行 (RCE)** | **“核弹级”漏洞**，面试必问。核心是利用JNDI注入。需理解原理、影响范围和修复方案。                |
| **Apache Struts2** | **CVE-2017-5638**               | **远程代码执行 (RCE)** | **经典中的经典**，导致了Equifax公司的大规模数据泄露。利用`Content-Type`头注入OGNL表达式。  |
|                    | **CVE-2018-11776**              | **远程代码执行 (RCE)** | 另一个核心RCE漏洞，由命名空间配置不当引发。                                      |
|                    | **CVE-2023-50164**              | **路径遍历/文件上传**    | 文件上传功能存在路径遍历，可导致Getshell。                                    |
|                    | **CVE-2020-17530** / **S2-061** | **远程代码执行 (RCE)** | 影响广泛的RCE漏洞，OGNL表达式注入。                                        |
| **Spring 框架**      | **CVE-2022-22965**              | **远程代码执行 (RCE)** | **“Spring4Shell”**，影响JDK 9+的Spring MVC应用。面试高频。               |
|                    | **CVE-2022-22963**              | **远程代码执行 (RCE)** | Spring Cloud Function的SpEL表达式注入漏洞。                           |
|                    | **CVE-2022-22947**              | **远程代码执行 (RCE)** | Spring Cloud Gateway的Actuator API SpEL表达式注入。                 |
|                    | **CVE-2022-22978**              | **权限绕过**         | Spring Security中RegexRequestMatcher的权限绕过漏洞。                  |
| **Tomcat**         | **CVE-2017-12615**              | **远程代码执行 (RCE)** | 在Windows上开启PUT方法，可上传Webshell。                                |
|                    | **CVE-2020-1938**               | **文件包含/读取**      | **“Ghostcat”** 漏洞，利用AJP协议（8009端口）读取或包含文件。                    |
| **WebLogic**       | **CVE-2017-3506**               | **远程代码执行 (RCE)** | WebLogic WLS组件的RCE漏洞。                                        |
|                    | **CVE-2018-2628**               | **远程代码执行 (RCE)** | 经典的T3协议反序列化漏洞。                                               |
|                    | **后台弱密码**                       | **弱口令**          | 了解WebLogic常见后台弱口令（如`weblogic/Oracle@123`）及部署war包Getshell的方法。 |
| **Apache Shiro**   | **CVE-2016-4437**               | **远程代码执行 (RCE)** | **“Shiro-550”**，因`rememberMe`加密密钥硬编码导致的反序列化漏洞。面试常问。          |
| **Fastjson**       | 多个CVE                           | **远程代码执行 (RCE)** | **国内Java应用广泛**，反序列化漏洞频发。需了解`@type`和`AutoType`等概念。            |
| **Redis**          | **未授权访问**                       | **未授权访问**        | 了解其危害，如结合SSH公钥或写入Webshell获取服务器权限。                            |
| **Django**         | **CVE-2022-34265**              | **SQL注入**        | Django `Trunc`和`Extract`函数的SQL注入。                            |
flask：Python Web 必学，重点看 SSTI（服务端模板注入）。
nginx：学习解析漏洞（如 CVE-2013-4547）或目录穿越。
jenkins：DevOps 环境常见，学习 Groovy 脚本执行拿权限。
gitlab：学习 CVE-2021-22205 等 RCE 漏洞。
